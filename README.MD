### 1. Projey Klonlama
```bash
git clone [https://github.com/veybit148/finans-proje.git](https://github.com/veybit148/finans-proje.git)
cd finans-proje
```

### 2. Docker İmajını Derleme
```bash
docker build -t finans-skorlama-app .
```

### 3. Sistemi Başlatma
```bash
docker run -it --rm finans-skorlama-app
```
